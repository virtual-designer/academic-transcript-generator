# Academic Transcript Generator

This is a project for the CSE115L course at my university.

## Building & Running The Project

### GNU/Linux

#### Prerequisites

1. A C compiler, preferably the GNU C Compiler (gcc) version 14 or later
2. GNU Make

To build and run the project, run:

```bash
make run-linux
```

### Darwin (macOS)

#### Prerequisites

1. A C compiler, preferably the Apple Clang C Compiler
2. GNU Make

To build and run the project, run:

```bash
make run-darwin
```

### Windows

Simply open the `src\atsgen.c` file in Code::Blocks.
Then, to run: Build > Build & Run. This should build and run the project.
